# 多波束后处理工作台 (MBES Workbench)

浏览器端多波束测深后处理系统：TypeScript + WebGPU + IndexedDB，零运行时依赖。

## 运行

```bash
pnpm install
pnpm dev        # 开发
pnpm build      # 构建（dist/ 约 60KB）
pnpm test       # 全部测试（含精度验证与性能基准）
```

首次使用：航次管理 → 「生成测试航次」（含海山/沟槽/沉船地形、姿态跳变、外侧波束噪声、粗差、潮位缺测段），生成后自动全航次重算。

## 页面

| 页面 | 功能 |
|---|---|
| 航次管理 | 航次/测线列表、测试数据生成、单线/全线重算（GPU 计时）、相邻线内符合统计、存储占用 |
| 声速剖面 | CTD 投放管理（时间/位置）、剖面图与编辑、每 ping 自动匹配最近剖面、换剖面全线 GPU 重算、精度验证 |
| 安装校准 | Patch test：横摇（平坦海底往返线）闭式最小二乘、纵摇/艏向（海山重叠线）扫描重分箱；滑块拖动两线横截面实时叠合；真值对照 |
| 条带清理 | 三维点云旋转框选删点、横截面逐 ping 检查、中位数面 + nσ 自动滤波；剔除只打标记可恢复 |
| 网格成图 | 格网 DEM（点数/标准差/不确定度，空格留空）、晕渲 + 深度色带、自动等深线、IHO 特等/一等覆盖检查与补测建议线、框选放大找最浅点、两点量测（船长） |
| 设置 | 安装偏差、杆臂/吃水、不确定度模型、正下方/外侧分开角度截断、重叠区 cos²β 入射角加权、IHO 等级、GPU 基准测试 |

## 核心算法与验证

- **声线追踪**（`src/core/ray_trace.ts`）：分层常梯度模型，Snell 定律 p=sinθ/c 守恒，每层 dx/dz/dt 闭式解（圆弧），处理等速层、正下方（p≈0）、折射翻转。
- **独立验证**（`src/core/ray_trace_num.ts`）：RK4 沿程数值积分，与解析解互为独立路径。测试结果：全角度（0–70°）全时段深度差 < 水深千分之一（实测最大相对偏差 ~1e-5 量级）。
- **地理配准**（`src/core/georef.ts`）：波束方向经安装偏差 + 姿态矩阵转到 NED 导航系，取出射角/方位角后沿方位平面二维追踪——水平分层假设下的精确解（姿态影响出射角本身，而非事后旋转终点）。
- **端到端**（`tests/e2e.test.ts`）：模拟生成（独立欧拉沿程积分求旅行时）→ 处理链解算 → 对比真实海底：4 万样本系统偏差 −10mm，RMS 98mm（含注入噪声）。
- **性能**：CPU 参考路径 2.4M 波束/s（2 万 ping × 512 波束 = 4.3s）；WebGPU 计算着色器（`src/gpu/shader.ts`）与 CPU 路径逐行对应，浏览器内基准测试见设置页，5 秒指标自动判定。

## 坐标与符号约定

- 船体系：x 艏向 / y 右舷 / z 向下；姿态矩阵 R = Rz(艏向)·Ry(纵摇)·Rx(横摇)，艏向北顺时针、纵摇艏抬为正、横摇右舷下沉为正。
- 图深 = 射线深度 + 换能器吃水 − 升沉(上为正) − 潮位(基准面向上为正)；吃水定义到换能器，杆臂只影响水平位置。
- 波束角右舷为正；`across` 为船体系带符号横向距离（patch test 修正公式用）。
- 标记：0 正常 / 1 清理剔除 / 2 未到底 / 3 角度截断 / 4 潮位缺测；剔除只打标不动原始数据。

## 已知简化

- 局部平面投影（WGS84 曲率半径），测区尺度足够；大测区可换 UTM 分带。
- IHO 覆盖检查按格网点数 + 合成不确定度近似 S-44，未实现特征探测（cubic feature）条款。
- 时延（latency）参数保留在数据模型与设置中，模拟真值为 0，未参与解算。
- 三维点云为 Canvas 投影渲染（非 WebGPU 管线），抽稀至约 15 万点绘制。
